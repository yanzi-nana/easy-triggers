# Easy Triggers

A starter Geode mod project for Geometry Dash.

## Current scope
This repository currently contains:
- A small C++ trigger-sequence data model.
- Unit tests for that model.
- A GitHub Actions workflow intended to build Windows and Android packages.

The in-game editor, real trigger execution, preview, undo, presets, and Workshop are not implemented yet.

## Build
Configure with a compatible Geode SDK and build using CMake. See the GitHub Actions workflow for the CI setup.
